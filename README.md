Leonida Legend — the complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade, a guide in our own words with named sources for each trophy, a five-stage roadmap to the platinum, missable flags, and a checklist with localStorage progress, export/import, kind and grade filters, search and a spoiler-safe mode.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The guide is plain static files under `app/` — no build step, no network. `main.ts` hands it in by copying `app/` and `screenshots/` to the output directory and writing `dossier.json`.
